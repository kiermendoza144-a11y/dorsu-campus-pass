3. Conceptual Bridge: Java Android & Web HTML/CSS vs React Native

If you already know Java (Android Studio) and Web Development (HTML/CSS/JS), React Native is simply a modern convergence of both! Explore the interactive tabs below to map your existing skills:

How visual elements translate from Android Java XML, Web HTML, and React Native JSX:

Java (Android XML) Android
Uses native Android View XML tags compiled into Android bytecode:
<LinearLayout
  android:orientation="vertical">
  <TextView android:text="Hello" />
  <ImageView android:src="..." />
  <Button android:text="Tap" />
</LinearLayout>
Web (HTML5) Browser DOM
Uses browser DOM elements rendered inside a web browser engine:
<div class="container">
  <p>Hello</p>
  <img src="..." />
  <button>Tap</button>
</div>
React Native (TypeScript) Cross-Platform
Uses cross-platform JSX primitives that map to REAL native UI:
<View style={styles.container}>
  <Text>Hello</Text>
  <Image source={{ uri: ... }} />
  <Pressable>
    <Text>Tap</Text>
  </Pressable>
</View>
💡 Key Takeaway: In React Native, <View> compiles to an actual android.view.ViewGroup on Android and UIView on iOS! It is not a web browser wrapper.

Comparing layout attributes, density pixels, and default directions:

Java Android XML Android
Attributes in XML; density-independent pixels (dp):
android:layout_width="match_parent"
android:orientation="vertical"
android:padding="16dp"
android:background="#FFFFFF"
Web CSS Web
CSS stylesheets; defaults to row direction; unit strings:
.container {
  display: flex;
  flex-direction: row; /* DEFAULT! */
  padding: 16px;
  background-color: #FFFFFF;
}
React Native StyleSheet React Native
JavaScript objects; defaults to column; unitless DP numbers:
const styles = StyleSheet.create({
  container: {
    flex: 1,
    flexDirection: 'column', /* DEFAULT! */
    padding: 16, /* Unitless DP */
    backgroundColor: '#FFFFFF',
  }
});
⚠️ The #1 Pitfall for Web Developers: In Web CSS, flex-direction defaults to row (horizontal). In React Native, it defaults to column (vertical), which perfectly matches Android's LinearLayout orientation="vertical"!

Imperative DOM/View Mutation vs. Declarative Reactive State:

Java (Imperative) Java Android
You manually find the view and tell the OS HOW to update:
TextView tv = findViewById(R.id.counter);
Button btn = findViewById(R.id.btnScan);
int count = 0;

btn.setOnClickListener(v -> {
    count++;
    tv.setText(String.valueOf(count));
});
React Native (Declarative) React Native
You declare WHAT the screen looks like; React updates it automatically:
const [count, setCount] = useState(0);

return (
  <View>
    <Text>{count}</Text>
    <Pressable onPress={() => setCount(c => c + 1)}>
      <Text>+1 Scan</Text>
    </Pressable>
  </View>
);
💡 Key Takeaway: In Java, you mutate UI elements directly via setters (tv.setText()). In React Native, you update the state variable (setCount), and React's virtual engine automatically re-renders the exact text node!

Passing Parameters to Reusable UI Components:

Java Class Constructors / Setters Java OOP
Data passed into class constructor or public setters:
StudentCard card1 = new StudentCard(
    "Juan Dela Cruz", 
    "2024-008492-MT"
);
containerLayout.addView(card1);
React Native Props (JSX Attributes) React Native
Data passed as typed attributes in JSX:
<StudentCard 
  student={juanProfile} 
  isActive={true} 
/>
💡 Key Takeaway: Props are immutable (read-only) in the child component. They are identical to passing arguments to a function or constructor.

Module 2 — Core Primitives & JSX Anatomy Exercise 2

In mobile development, there is no DOM. Web tags like <div>, <p>, and <button> do not exist. Instead, React Native provides native primitives:

Web Element (HTML) React Native Primitive Key Mobile Characteristics
<div> <View> Flex container by default; flexDirection is column (vertical).
<p>, <span>, <h1> <Text> Mandatory for all text. Putting raw text in <View> crashes the app.
<img> <Image> Remote URIs require explicit width and height in styles.
<button> <Pressable> Modern touchable primitive supporting hover, focus, and dynamic pressed states.

Step 3.2: Reusable StudentCard Component

src/components/StudentCard.tsx 
import React from 'react';
import { StyleSheet, Text, View, Image } from 'react-native';
import { StudentProfile } from '../types/student';
import { StatusBadge } from './StatusBadge';

interface StudentCardProps {
  student: StudentProfile;
  isActive: boolean;
}

export const StudentCard: React.FC<StudentCardProps> = ({ student, isActive }) => {
  return (
    <View style={styles.card}>
      <View style={styles.topRow}>
        <Image source={{ uri: student.avatarUrl }} style={styles.avatar} />
        <View style={styles.details}>
          <Text style={styles.name}>{student.name}</Text>
          <Text style={styles.idNumber}>{student.idNumber}</Text>
          <Text style={styles.program}>{student.program}</Text>
          <Text style={styles.yearLevel}>{student.yearLevel}</Text>
        </View>
      </View>
      <StatusBadge isActive={isActive} />
      <Text style={styles.campus}>Campus: {student.campus}</Text>
    </View>
  );
};

Module 4 — Dynamic State Management with useState Exercise 4

Implement dynamic gate scans and administrative access toggles using React's useState hook.

src/components/ScanCounter.tsx 
import React from 'react';
import { StyleSheet, Text, View, Pressable } from 'react-native';

interface ScanCounterProps {
  count: number;
  onScan: () => void;
  onReset: () => void;
}

export const ScanCounter: React.FC<ScanCounterProps> = ({ count, onScan, onReset }) => (
  <View style={styles.container}>
    <Text style={styles.title}>Campus Gate Verification Log</Text>
    <View style={styles.counterDisplay}>
      <Text style={styles.label}>Today's Gate Entries:</Text>
      <Text style={styles.value}>{count}</Text>
    </View>
    <View style={styles.btnRow}>
      <Pressable style={styles.btnPrimary} onPress={onScan}>
        <Text style={styles.btnText}>+1 Scan at Gate</Text>
      </Pressable>
      <Pressable style={styles.btnSecondary} onPress={onReset}>
        <Text style={styles.btnSecText}>Reset Scans</Text>
      </Pressable>
    </View>
  </View>
);
💡
Functional State Updates: Always write setGateScans(prev => prev + 1) instead of setGateScans(gateScans + 1) to guarantee accurate state reconciliation during fast button taps.
